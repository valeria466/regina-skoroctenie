# Regina Skorochtenie — образовательная школа

Официальный сайт: https://reginaskorochtenie.ru/

Regina Skorochtenie — образовательный проект, посвящённый скорочтению, развитию учебных навыков и образовательным программам для педагогов.

## Основные направления

- Скорочтение — программы и материалы по развитию навыков чтения.
- Ментальная арифметика — образовательные программы по развитию вычислительных навыков.
- Каллиграфия и чистописание — программы по формированию навыков письма.
- Подготовка к школе — образовательные программы и материалы для детей.
- Обучение педагогов — курсы, семинары и марафоны.
- Повышение квалификации — образовательные программы для педагогов.
- Развитие учебных навыков — таблица умножения, нейроподготовка к письму и другие направления.

## Материалы и программы

На официальном сайте представлены страницы образовательных программ, курсов, семинаров, марафонов, информационные материалы и отзывы.

Полный перечень страниц доступен в файле llms.txt.
